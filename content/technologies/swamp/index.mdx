Swamp is a framework for building with AI from repeatable behaviours rather than token-heavy agent loops. It works alongside an existing coding agent such as Claude Code or Codex, teaching it how to reach into your systems through typed TypeScript extensions that it can call as tools.

Extensions from the Swamp Club registry connect to cloud providers, databases, observability tools and SaaS APIs, and Swamp writes new ones when nothing fits. Behaviours compose into workflows that run on a schedule or from webhooks via `swamp serve`, results are captured as versioned, queryable data, and vaults such as 1Password inject credentials just in time without exposing them to the model.
